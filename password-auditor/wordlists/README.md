# Wordlists

`common_passwords.txt` is a **small educational subset** of widely published
"worst / most common passwords" (the kinds of entries found in public lists such
as [SecLists](https://github.com/danielmiessler/SecLists) `Passwords/Common-Credentials`).

- **Purpose:** local offline checks in this portfolio tool — not a full breach corpus.
- **License note:** SecLists is typically MIT-licensed; this file contains only
  short, commonly cited example passwords rewritten for the lab. Do not treat it
  as a complete dump or as evidence that any real account was breached.
- Point `--wordlist` at a larger file (e.g. a full SecLists common list) for deeper audits.
